# async-only / 공통 TPS 검증

2026-09-14에 독립 적대적 리뷰 2인 최종 승인 후 live E2E를 실행했다.

- 오프라인 84개·하위 테스트 14개 통과. RuntimeWarning 오류 승격 실행,
  ruff, mypy 53파일, compileall, SKILL 검증과 CodeGraph 갱신 통과.
- 공개 서비스의 인자·모델·페이지 종료 규칙 보존, 모든 요청·재시도·리다이렉트
  토큰 과금, 스트림 취소·50MB 상한·주입 세션 수명을 독립 검증했다.
- 리뷰에서 발견한 외부 커스텀 호스트에 자동 키 첨부, provider 오류의 키 echo,
  디버그 상태/재시도 표시, URL 입력/trace 키 노출을 수정하고 재검증했다.
- 스트리밍 리다이렉트 중간 본문은 읽지 않고 닫아 메모리 상한 우회를 막는다.
  원문 모델 검증 후 디버그 반환값을 마스킹해 숫자 필드 검증도 보존한다.
- README/SKILL/docs의 비동기 예제 6개 실행 성공.
- 리뷰 후 live E2E 4개 통과: 공개 HeritageClient 목록·상세·디버그,
  목록/상세/이미지/동영상 원문, 이전 HTTP URL 리다이렉트, GIS XML 관찰.
- GIS 테스트는 공급자가 반환하는 XML의 `code=500` 오류 envelope를 확인한다.
  GIS 정상 데이터 조회 성공으로 계산하지 않는다. HTTP 403은 관측되지 않았다.

`AsyncTokenBucket`은 다른 전환 라이브러리와 동일 구현이며 기본 5 TPS,
주입 버킷 우선, FIFO 대기·취소·단일 이벤트 루프 계약을 따른다.
