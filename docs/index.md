# python-krheritage-api

`python-krheritage-api`는 국가유산청 및 관련 기관의 공개 API/파일데이터를 TripMate에서
직접 소비할 수 있는 Python 라이브러리로 정리하는 프로젝트입니다.

- GitHub repository: `https://github.com/digitie/python-krheritage-api`
- Python import module: `krheritage`
- TripMate source/provider name: `python-krheritage-api`
- PyPI publication: disabled by project decision

## Current Scope

Phase 0/1 covers the package scaffold, configuration, common code tables,
exception hierarchy, and initial model/transport foundations. API endpoint
services are added in later phases.
