# python-krheritage-api

`python-krheritage-api`는 국가유산청 및 관련 기관의 공개 API/파일데이터를 TripMate에서 직접 소비할 수 있는 Python 라이브러리로 정리하는 프로젝트다.

- GitHub repository: `https://github.com/digitie/python-krheritage-api`
- Python import module: `krheritage`
- TripMate source/provider name: `python-krheritage-api`
- PyPI publication: project 결정에 따라 비활성화

## 문서 언어 정책

이 저장소의 모든 Markdown/RST 문서는 한글로 작성한다. 공식 API field, code identifier, 명령어, URL, provider 원문은 필요한 경우 원문을 유지한다.

## 현재 scope

현재 검색·상세·행사·GIS 서비스, 카탈로그 디버그와 페이지 순회를 native async로 제공한다. 설정·코드표·모델·파싱도 제공하며 아직 비어 있는 부가 서비스는 이번 전환 범위에서 새로 구현하지 않는다.
